# Mersad

Mersad by Nikoloz Khipashvili, version 1.000.

- Font page: https://typeface.ge/ka/font/Mersad
- Original download: https://typeface.ge/ka/font/542/download
- Author's project: https://www.behance.net/gallery/145150505/Mersad-Free-Variable-Typeface

The Regular (400), Medium (500), Semi Bold (600), and Bold (700) OpenType files
from the original archive were converted to WOFF2 with FontTools 4.68.0.
The fonts retain their original glyphs and copyright metadata, including Georgian,
Mtavruli, Latin, and the Georgian lari symbol. Vite bundles these local files;
the application makes no external font requests.
